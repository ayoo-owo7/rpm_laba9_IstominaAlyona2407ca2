# Лабораторная работа №9
Принцип внедрения зависимостей (Dependency Injection, DI) — это техника в программировании, при которой объект получает необходимые ему зависимости извне, а не создаёт их самостоятельно. Это позволяет снизить связанность между компонентами системы, упростить тестирование, повторное использование кода и его сопровождение.

Сервис в MVVM — это класс, инкапсулирующий определённую функциональность, которая
не относится к бизнес-логике или данным (например, работа с файловой системой, вызов API,
отображение диалогов).
<img width="1022" height="333" alt="image" src="https://github.com/user-attachments/assets/dfd2b2ae-9668-4f08-8774-deb60d4a594b" />


- Обработка зависимостей без DI возможна, но это может привести к сбоям работы приложения.
- DI — это просто эффективная идея, согласно которой возможно обрабатывать зависимости вне зависимого класса.
- Эффективнее всего использовать DI в определенных частях приложения. Многие фреймворки этому способствуют.
- Фреймворки и библиотеки не нужны для DI, но могут во многом помочь.
